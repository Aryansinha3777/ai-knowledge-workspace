# AI Knowledge Workspace

A full-stack RAG-based knowledge management platform. Users upload documents, which are chunked and embedded into PostgreSQL (pgvector), enabling semantic search and LLM-powered question answering with source citations.

**Status:** 🚧 In development

## Tech Stack
- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL + pgvector
- ORM: Prisma
